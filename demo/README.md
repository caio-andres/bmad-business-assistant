# Dados de demonstração (fictícios)

Tudo nesta pasta é **inventado** para demonstrar o Alicerce sem acessar sistemas reais.
A organização fictícia é `acme` e as siglas são `PAG` (pagamentos), `CRT` (cartões) e `ONB` (onboarding).

- `repos/`: repositórios de produto fictícios no padrão `<org>-<sigla>-<app|infra>-<nome>`, lidos pelo contexto de produto quando `REPO_SOURCE=local`.
- `acme-onb-app-cadastro` traz um `bmad-context.md` escrito "pelo time", que tem prioridade sobre o resumo gerado.
